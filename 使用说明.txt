============================================================
使用说明（请先读这一页）
============================================================

> 影之诗助手汉萨改 V1.1.2
> 绿色免安装，解压即用。不写游戏目录、不改游戏文件、不需要绑定任何东西。

● 这个工具能做什么

  - 胜率：开战瞬间读双方等级、血量、场上随从，按时间预算做蒙特卡洛模拟（普通局 300ms、有召唤连锁 1000ms）
  - 掉血概率：只显示**伤害区间 + 最大伤害**（我方受伤 X~Y 点（最大 Y）、造成伤害 X~Y 点（最大 Y））
  - 战绩面板：整局结算记录：编号、主战者、名次、自动推断阵容、流派、备注、时间（可关）
  - 悬浮窗：平时是一个圆形悬浮球，点开看我方光环效果、带任务的计数与本局进化次数
  - 阶段感知：运营 / 战斗 / 大厅 各有文案，不会乱报胜率
  - 直播模式：在控制台设置里开启，悬浮层变不透明，OBS「窗口采集」能直接抓到
  - AI 陪玩：透明 Live2D 鲸鱼娘宠物，对局中检测抽牌 / 出牌 / 掉血，
    用你填的 LLM 说 1~2 句短评（可选 Edge TTS 语音）；没填 API Key 时不启用

● AI 陪玩怎么开

  1. 控制台「影之诗」页 → 「AI 陪玩」→ AI 设置；
  2. 选「提供商」会自动填 Base URL 和模型（火山方舟有 Seed-Evolving / Seed 2.1 Pro / Turbo；
     Seedance 是视频生成模型，聊天用不了），也可以手动改；
  3. 点「测试 AI」确认能连通（失败会显示具体原因：HTTP 状态码 / 网络错误）；
  4. 勾选「启用陪玩」→ 保存；
  5. 运行 `run_companion.py`（或从控制台启动）后，鲸鱼娘会出现在屏幕右下角。
     右键宠物：锁定位置 / 打开控制台 / 关闭；左键拖动。
  6. 语音 = Edge TTS（云端、免费、不占显存），每句生成临时 mp3，播完立即删除。
     注意：鲸鱼娘 Live2D 模型为 CC BY-NC-SA 4.0（非商用），作者为b站氵六青。

● 模型替换教程（把鲸鱼娘换成其它 Live2D 模型）

  （右键菜单已移除「导入模型」入口；如需换模型，可手动改
  pet_config.json 的 model 字段指向 xxx.model3.json，重启宠物生效。）

【一、需要安装吗？放哪个文件夹？】

● 不用安装

解压到任意文件夹，双击 启动.bat 就能用。

● 放在哪里

  - ✅ 推荐：D:\ShadowverseHelper\：全英文路径，最稳
  - ✅ 也可以：桌面、Documents 下：只要不涉及系统保护目录
  - ❌ 不要：C:\Program Files\、C:\Windows\：需要管理员权限才能写日志，会报错
  - ⚠️ 中文路径：实测可用，但不推荐；个别环境可能因编码问题出故障

------------------------------------------------------------

【二、需要绑定什么吗？】

不需要。

- ❌ 不需要安装到游戏目录
- ❌ 不需要绑定模拟器
- ❌ 不需要注入 DLL
- ❌ 不需要修改游戏任何文件
- ❌ 不需要填账号密码

程序只是以只读方式打开游戏进程，读几个数值，然后关闭句柄。

------------------------------------------------------------

● 双击 启动.bat 不会留下黑框

  启动器会用 pythonw 在后台把控制台拉起来（托盘里有图标，双击即可显示窗口）；
  启动窗口只闪一下就自己关掉。
  如果启动失败，详细信息会写在：svwb-probe\logs\console-app.log

【三、怎么启动？】

● 推荐顺序

``
1. 打开 MuMu 模拟器 → 进入《影之诗》→ 进入「影之幻境」
2. 双击 启动.bat
3. 控制台自动弹出（不会出现黑色命令行窗口）
`

● 先启动哪个都行

- 先启动助手：它在后台等游戏进程出现（最多 3 小时）
- 先启动游戏：助手启动后立刻就能读到

● 运行环境：启动时自动检查，缺什么装什么

**每次**双击 启动.bat 都会先做一次快速自检（静默，约 1 秒，看不到任何窗口）：

  - 环境齐全 → 直接往下走，跳过安装（你只会看到"正在启动控制台"）；
  - 缺任何一样 → 自动安装，这时才会显示进度（需要联网，可能要几分钟）：
      · Python 3.10+：优先 winget，其次 python.org 官方安装包（按当前用户装，不需要管理员）
      · Node.js 18+：下载官方 zip 解压到 svwb-probe\node\（免安装、免管理员）
      · Pillow / NumPy：pip 装

  下载都带超时；官网不通会自动换国内镜像（Node 用 npmmirror，Python 用华为云，
  pip 用清华源），所以不用自己找代理。

所以换电脑、重装系统、删了 python 都不用管，直接双击 启动.bat 就行。
自检只看"在不在、版本够不够"，什么都不改；安装过程记在 svwb-probe\logs\环境检查.log。

如果自动安装失败：双击「修复环境.bat」重试（会重新检查，已就绪的不会重复下载）。

● 关于那个黑色窗口

已经没有了。 全部进程都用 pythonw.exe 启动（GUI 子系统），
不会再弹命令行窗口。

> 如果你还看到一个标题像 C:\Users\...\.dsh\dsh-runtimes\... 的黑窗口，
> 那是开发环境本身（DeepSeek Harness），不是这个工具。

------------------------------------------------------------

【四、管理员权限】

建议用管理员身份运行 启动.bat。

原因：Windows 规定，普通权限的进程不能读取管理员权限进程的内存。

- 如果 MuMu / 游戏是以管理员运行的 → 助手也必须是管理员
- 如果两者权限一致 → 普通权限也能读

判断方法：控制台显示「运行中」但一直不出胜率，多半就是权限不一致。

【六、游戏必须用「窗口模式」】

如果游戏是全屏独占，Windows 不允许其他窗口盖在它上面，
悬浮层和面板会被游戏挡住，看起来像没启动。

● 怎么改

MuMu 模拟器 → 右上角设置 → 显示 → 把「全屏」改成 窗口模式 或 无边框窗口。

【七、四个窗口分别是什么（影之幻境模块）】

  控制台现在分两个模块（顶部页签切换）：

    · **影之幻境**：胜率悬浮层 / 战绩面板 / 悬浮窗 / 阵容统计（下面几节就是它们）
    · **影之诗**：记牌器 + 历史胜率（见第十七节）

● 启动行为（重要）

  控制台启动时**不会自动打开所有插件**：按上次关闭时的状态恢复；
  第一次安装 / 没有记录时**全部关闭**，需要到对应模块里点「全部启动」或「打开」。
  两个模块互不连带：影之幻境启动不会自动开记牌器，反之亦然。

● 窗口的层级关系（重要）

四个窗口都是「**游戏在前台时压在游戏画面上，切走就被别的窗口盖住**」：
  - 打游戏时：面板显示在游戏画面之上
  - 你把浏览器 / 资源管理器等窗口切到前台：面板立刻取消置顶，
    那个窗口会**盖住**面板，不会一直压在所有窗口最上面
  - 想让面板重新出现：点一下游戏窗口即可

程序识别"游戏"用的是**进程路径**（含 Shadowverse / MuMu 的那个进程），
不会把网页标题里的"影之诗"当成游戏。

● 锁定（点击穿透）

设置里勾选「锁定」后，鼠标放在面板上**不影响游戏操作**：
点击会直接穿透到下面，游戏照常响应。要解锁请用控制台的「锁定」开关
（锁定状态下窗口收不到鼠标事件，双击是解不开的）。

● 胜率悬浮层显示什么

`
胜 34%  ·  败 38%  ·  平 28%
我方受伤：6~11 点（最大 11）
造成伤害：0~9 点（最大 9）
`

- 没对局时显示：快来一场紧张刺激的影之幻境喵
- 战斗中正在算：读取中……
- 运营阶段：运营ing……正在等待战斗阶段喵

● 战绩面板显示什么

`
1  罗文  第3名  精灵  12:18:15   ← 编号 + 主战者 + 名次 + 阵容 + 时间
   [流派________] [备注________]  ← 两行输入框，你自己写，失焦自动保存
`

- 编号：按显示顺序 1、2、3…
- 名次：出局后判定，写在主战者名字后面；第 1 名是金色
- 阵容：自动推断（3 张以上同族 → 该族，否则「混合随从」），只用于显示
- 时间：开这一局的时刻，放在行末；可在「战绩面板设置 → 显示时间」关掉
- 流派 / 备注：你自己填，不会被自动值覆盖
- 没有「已出局 / 进行中」这类状态行，也不显示血量数值

【八、设置都是「改完立刻生效」】

不需要重启任何窗口。 所有设置都是热生效：

  - 控制台不透明度：控制台设置 拖动即变
  - 关闭按钮行为（隐藏到托盘 / 退出）：控制台设置 选完即生效
  - 控制台字号：控制台设置 拖动即变
  - 直播模式（不透明背景）：控制台设置 勾选即生效
  - 胜率悬浮层字号 / 透明度 / 缩放 / 位置：控制台 → 悬浮层设置 即时
  - 锁定（点击穿透）：控制台 → 悬浮层设置 即时
  - 战绩面板字号 / 背景与文字透明度 / 尺寸 / 显示时间：控制台 → 面板设置 即时
  - 悬浮窗字号 / 不透明度 / 宽高：控制台 → 悬浮窗设置 即时

> ⚠️ 锁定后不能用双击解锁（点击穿透时窗口收不到鼠标事件）。
> 请用控制台的「锁定」开关解锁。

【九、关闭行为】

点 ✕ 时按设置执行：

  - 隐藏到托盘（默认）：窗口消失，程序继续在后台跑，判定器不中断。双击托盘图标恢复
  - 退出程序：全部进程退出（同时清空战绩记录）

— 按钮 = 最小化到任务栏（点任务栏图标可还原），和「隐藏到托盘」是两回事。

【十、直播怎么接入】

推荐做法：用控制台里的「直播模式」，不需要额外开窗口。

  1. 控制台 → 设置 → 勾选「直播模式（不透明背景）」
  2. OBS → 来源 → + → 窗口采集 → 选标题是「影之幻境 · 胜率」的那个窗口
  3. 「采集方式」优先选 Windows 10 (1903 及以上)；若黑屏再试 BitBlt
  4. 右键该源 → 变换 → 适应屏幕

● 为什么透明模式抓不到

悬浮层用的是分层窗口（WS_EX_LAYERED + 抠色 + 整体透明度），
OBS 的窗口采集抓分层窗口通常得到**全黑**画面。
开启直播模式后程序会移除分层属性、把背景改成不透明，就能正常采集了。

● 采集到的画面范围

OBS 抓的是窗口**客户区**（不含标题栏），所以悬浮层多大，画面就多大。
需要固定构图时，先把悬浮层拖到你想要的位置和大小，再在 OBS 里锁死。

● 备选方式一：独立的直播信息窗

如果不想改悬浮层的样式，可以另开一个不透明的窗口给 OBS 抓：

  pythonw live_mode.py --x 40 --y 40 --w 420 --h 160

  - 它是普通不透明窗口，标题「影之幻境 · 直播信息」，OBS 窗口采集它即可
  - 可直接按住拖动、拖边框缩放，字体会跟着窗口大小适配
  - 加 --log live_mode.log 可以把运行信息写进文件，排查时有用
  - 默认置顶；不想挡游戏可以加 --no-topmost（OBS 采集不依赖置顶）
  - 加 --borderless 可去掉标题栏，此时右上角有 × 关闭、右下角有 ◢ 缩放

● 备选方式二：区域定时截图 + 图片源

  pythonw live_capture.py --rect 40,40,420,160 --out live.png --loop 0.5

这会每 0.5 秒把屏幕指定矩形存成 live.png（覆盖同一个文件），
OBS 里加一个「图片源」指向它即可。缺点是刷新率受截图速度限制。

● 常见问题

  - 抓到全黑：没开直播模式，或者 OBS 用了「游戏采集」而不是「窗口采集」
  - 画面尺寸不对：OBS 抓客户区，用窗口实际大小去对
  - 直播模式下文字仍淡：那是悬浮层自己的「文字不透明度」设太低，去设置里调
  - 双显示器 / 缩放 150% 以上：OBS 的坐标和程序里的坐标口径可能不同，
    以 OBS 里看到的画面为准去调窗口位置

【十一、常见问题】

● Q1：双击 启动.bat 出现一堆「不是内部或外部命令」或中文乱码

原因：bat 文件的编码和 cmd 的代码页对不上（早期版本存成了 UTF-8）。

现在有三重保险，正常不会再有：

  1. 启动.bat / 修复环境.bat 本身是 GBK 编码；
  2. 开头执行 chcp 936，强制 cmd 用中文代码页——
     就算系统开了「Beta：使用 Unicode UTF-8 提供全球语言支持」也不乱；
  3. 所有**命令**都是纯英文，就算 echo 的中文仍然显示成乱码，工具照样能启动。

如果还是报「不是内部或外部命令」：

  - 多半是文件在传输 / 解压 / 编辑时被改过编码 → 重新解压一次；
  - 或者关掉系统设置里的「Beta：使用 Unicode UTF-8 提供全球语言支持」，再试。

● Q2：一直卡在「没有找到可用的 Python」

现在第一次启动会自动检查、自动安装（见第三节），正常轮不到你看这条。
只有自动安装失败时才需要手动处理：

  1. 先把「修复环境.bat」双击一次——它会重新检查并再试一遍安装；
  2. 还不行就手动装正式版：https://www.python.org/downloads/
     安装时务必勾选 Add python.exe to PATH，装完再双击「修复环境.bat」；
  3. 实在不想装（或者公司电脑装不了），就把已有 python.exe 的完整路径
     写进 svwb-probe\python-path.txt：
       - 一行，只有路径，不要引号；
       - 存成 ANSI/UTF-8 都可以，但**不要带 BOM**（记事本另存为 UTF-8 会带 BOM，
         那样路径前面会多一个看不见的字符，程序就认不出来了）。

⚠️ 最常见的坑：系统里的 python 是「应用商店占位程序」（返回错误码 9009）。

判断：

`
python -c "print(1)"
`

- 输出 1 → 是真的
- 什么都不输出 / 弹应用商店 / 报错 → 是占位程序

关掉占位程序的别名：设置 → 应用 → 高级应用设置 → 应用执行别名，
把 python.exe / python3.exe 都关掉，然后重新双击「修复环境.bat」。

● Q3：一直不显示胜率

按顺序检查：

1. 游戏是不是全屏？ → 改窗口模式（第六节）
2. 权限是否一致？ → 用管理员运行
3. 是不是在运营/大厅？ → 只有战斗阶段才算胜率
4. 看日志：svwb-probe\logs\judge-out.txt，每场会打印
   模拟：预算XXXms 实耗XXXms 跑了N次
5. 光环加成看着不对：看 svwb-probe\logs\光环解析失败.log
   有内容 = 卡面文案没解析出来（会退化成“所有随从”加成），把那一行发我加规则；
   没有这个文件 = 光环解析都正常。

● Q4：显示「阵容还没铺开，补读一次」

开战后随从是一只只飞进场的。程序检测到「一边 0 张、另一边 ≥3 张」
这种明显不对称时会自动补读一次，取更完整的阵容。这是正常行为。

● Q5：胜率/掉血差一两点

见第十三节「已知限制」。

● Q6：Windows Defender 报毒

只读内存的脚本常被启发式误报。把整个文件夹加入信任即可。

● Q7：主战者头像显示成「?」

立绘需自己放：svwb-probe\hero-portraits\<heroId>.png（例如尤里亚斯是 1115.png）。

● Q8：截图越积越多

超过 2 小时自动删。启动时清一次，之后每 10 分钟清一次。

【十三、性能与精度】

● 出结果有多快

  - 普通对局：300ms 100~240ms
  - 有「谢幕曲召唤随从」的牌（不弑的团结者、慈颜的拥趸、引路船工、树海的战士、腐臭的僵尸…）：1000ms 约 1 秒

模拟是常驻 node 进程跑的（不用每次重启），所以固定开销几乎为零。
预算内会尽量多跑（通常几千到几万次），跑满即出结果。

● 已知限制

  - 名次：内存里可能读到重复快照；读不到就记 null，不编造
  - 掉血精度：实测误差约 ±1~2 点
  - 全屏游戏：必须改窗口模式
  - 仅 Windows：依赖 Windows API
  - 需要 Node.js：模拟引擎用 Node 跑
  - 极少见的技能：共 348 条随从技能，已覆盖 98%（战斗内只有 7 条没建模，其余是"战斗外时点"，本来就不参与结算）

【十四、安全说明】

全程只读游戏进程内存：

- ✅ OpenProcess 只申请 PROCESS_QUERY_INFORMATION | PROCESS_VM_READ
- ✅ 只调用 ReadProcessMemory`
- ✅ 不写内存、不注入、不 hook、不模拟输入、不改游戏文件

> ⚠️ 只读不等于零风险。游戏用户协议通常禁止第三方程序读取客户端数据，

【十五、悬浮窗（光环 / 计数）】

平时它不在屏幕上占地方，而是收成**一个圆形悬浮球**（右下角，金色小圈）：

  - 球上的数字 = 当前有几条我方效果（光环 + 其他从者效果）
  - **拖动球** → 移动位置（位置会记住，下次启动还在那儿）
  - **点一下球** → 展开面板；面板右上角「×」→ 收回成球（**不会关闭**，只能从托盘退出）
  - 展开时如果面板会被屏幕边缘挡住，会自动挪进来**完整显示**；
    但**收回成球后会回到你原来放的位置**（球不会跑）。拖过面板的话，球就落在面板的位置
  - **只要在局内（战斗/运营）就显示**——哪怕一条光环都还没有，也会显示球（数字 0 / ○）
  - 没进游戏 / 已经离开对局 → 球隐藏（进程还在跑）

● 面板里显示什么（三块）

**① 本局进化**（固定在最上面，和效果行一样排）

  本局进化                      4 次

  吃进化点、被效果进化、战斗阶段进化都算；超进化只算 1 次；三连合成不算。

**② 光环**（我方拿到过的，整局累积）

  精灵·随从进场 +4/+0        ← 森林骑士道·辛西亚
  幻境等级3或以下的随从进场 +3/+3  ← 商队猛犸象

  - 写效果本身，不写「光环 1/2」这种名字
  - 同种效果多张牌 → 合并成一行、数值累加
  - 对方的光环不显示（但会算进胜率）

**③ 带任务的计数**（只在我方**真的有这张牌在场**时出现；不显示来源）

这类是"带任务的计数"：**左边写条件、右边单独给数值**，不写 +X/+X，
也**不显示来源**（谁给的自己心里有数），不同能力各自一行：

  本局战斗梦魇随从进场数            3
  本局游戏被破坏的守护随从数量      1

  - 徒姬：基础形态「梦魇·随从进场 +6/+6」、进化「+12/+12」；
    超进化改成按 X 计算，X = 本局**战斗阶段**进入战场的梦魇随从数
  - 维尔伯特：基础「守护·随从面板 +1/+2」、进化「+2/+4」；
    超进化 +X/+2X，X = 本局被破坏的守护随从数
  - 没这张牌 / 不是对应形态 → 不显示（不会凭空列出来）

● 什么时候清空

  - 一场战斗结束 → 不清空，下一场继续累积
  - **这一局结束（被淘汰）→ 清空并隐藏**，下一局重新开始计数
  - 控制台里这一栏显示「运行中」就说明它一切正常

● 面板怎么认"形态"

  超进化/进化的形态优先从**卡对象上的进化状态字段**读；读不到时退回按卡号判断
  （基础 / 进化）。如果哪天发现超进化的数值没变，把 `logs/` 发过来，
  校准一个内存偏移就行。

● 来源 / 回合（已删除）

  为了省算力，面板**不再记录来源和回合**，也不再有二层详情窗：
  只显示「效果 + 数值」和常显的「本局进化」。
  想看是谁给的效果，游戏里点开那张牌就能看到。

● 高 DPI（缩放屏）下文字模糊？

  插件四个窗口（控制台 / 战绩 / 悬浮窗 / 胜率浮层）现在都按**真实分辨率**渲染，
  175% 缩放下也是清晰的（窗口大小按相同比例放大，观感不变）。
  如果某天界面位置看起来不对，可以临时关掉这个特性再启动：
     set SVWB_NO_DPI=1

。

【十七、影之诗模块（记牌器）】

  ● 怎么打开

    控制台顶部切到「影之诗」→ 点「记牌器」里的「打开」。

  ● 它做什么

    读取你这一局的卡组，列出每张牌「还剩几张没抽到」：

      · 灰色 = 已经抽到（进手牌、打出、进墓地都算）
      · 正常颜色 = 还在牌库里
      · 顶部依次显示「牌库剩余 N · 手牌 M · 爆牌 K」
      · 有卡洗回卡组时，牌库剩余前面会出现红色【洗回】标记

    只读你自己的数据，不读对手手牌/牌库。
    「牌库剩余」永远只数你自己的牌库：万一某一帧把你和对手认反了，
    这一帧的数字会被丢掉、沿用上一次的，不会跳出对手的牌库数。

  ● 手牌分区（V1.0 恢复）

    记牌器窗口最上面是「手牌」，然后才是「牌库」。1.1.0 ~ 1.1.1 期间这块
    是隐藏的（当时觉得游戏里手牌就在屏幕上，重复），V1.0 起恢复显示，
    原因是这里排好序、还标出「现在能不能打出」，比在屏幕上数更快：

      · 同名的牌并成一行，右边 ×2 表示手上有两张；
      · 费用不高于当前 PP 的牌，整行描金边、费用圆章和费用数字一起变金 ——
        一眼看出能打哪几张。PP 涨上来或者花出去，这些标识会立刻跟着变，
        不用重开记牌器；
      · 最左边那条细竖条是**职业色**（精灵青、皇家金、中立灰…），
        无论能不能打出都不会变色，方便对职业；
      · 标题右边写「可打出 N」；一张都打不出时改显示手牌张数；
      · 换牌（调度）阶段这块只显示「换牌中」，换完才列牌；
      · 嫌占地方：点「手牌」这个标题就能把整段收起（变成 ▸ 5 张），再点展开；
      · 手牌里空着的槽位（读出来是 0）不会列出「#0」这种行。

  ● 两个标签：我方 / 对方

    数值行下面有一条红线，「我方」「对方」两个标签挂在线上，点一下切换：

      · 我方（默认）= 你的手牌 + 牌库还剩哪些牌
      · 对方 = 两块：
          「已知衍生物」—— 从对手技能原文推出来、他手上可能多了哪些牌；
          「对手已知」—— 真读到的：对手打出过的牌 + 召唤到战场上的衍生物

    衍生物（token）就是那些只能由卡牌能力生成、不会组进卡组的卡；
    对手打出或者召唤上场，都会在这里列出来，并按它自己的类型归入
    「随从 / 法术 / 护符」三类（V1.0 起不再单列「衍生物」）。

  ● 进化点 / 进化标记（V1.1.2 新增）

    · 资源行末尾的 `EP 1/2·超2/2` 是你自己的进化点 / 超进化点（剩几个 / 上限几个）；
      切到「对方」标签，标题栏里也有对手的 `进化 1/2·超2/2`；
    · 读不到时这一小段不显示 —— 不会画出假数字；
    · 对手场上进化过的随从，类型栏会写 `随从·进化`（金色）或
      `随从·超进化`（玫红）；
    · 同名的两张随从一张进化一张没进化时，会**分成两行**显示，不会并成 ×2；
    · 进化标记是记忆式的：这张随从被击杀之后标记仍然保留，一直留到这一局结束。

  ● 「已知衍生物」这一栏是怎么来的（2026-11-11）

    对手**手里有什么**是读不到的（这块刻意不读），所以「入场曲给 1 张
    『解析的创造物』」这类效果，光看手牌只能数出“手牌 +1”。

    但很多卡的技能原文里写死了要给哪张牌，于是：对手打出某张卡时，如果它的
    技能里写着「将N张『某某』加入手牌」，这一栏就会**替它记一行**——比如打出
    `人偶长矛手`，下面就多一行 `改良型·悬丝傀儡`。

      · 这类行是**推出来的，不是看到的**：类型栏写 `推测·随从`（灰色）；
      · 只认四种时机：【入场曲】、【进化时】、【超进化时】、【谢幕曲】；
        谢幕曲那类要看到这张牌**被破坏进墓地**才补（弃牌、爆牌进墓地不算）；
      · 随机、同名、非公开、带条件的效果一律不猜 —— 比如
        `器械操纵者·吉尔克`（随机 + 同名 + 非公开），打了也不会多出任何行；
      · 【进化时】那类要看到它确实进化了才补 —— V1.1.2 起读的是随从对象上的
        进化状态字段，加 buff 加出来的身材不算；【超进化】会同时触发
        「进化时」和「超进化时」两份；
      · 技能写成「【进化时】发动与【入场曲】相同的能力」这种**引用式**的卡
        （例如悠然的滑手），也按被引用的那个时机补算；
      · 后来对手真把这张牌打出来了，「已知衍生物」这一栏**不改数量、也不移除**
        —— “这张是从哪张牌上拿到的”本身就是要留住的信息，真读到的那张会
        另外出现在下面的「对手已知」里；
      · 一局结束（换局 / 投降 / 对局结算）整栏自动清空，不会带到下一局；
      · 嫌这些行干扰，可以无视它们 —— 它们单独一栏，不跟真读到的混在一起。

    这一块在后台一直统计，跟你当前看的是哪个标签无关；切回来看到的就是累计值。
    中途因为长考 / 结算画面短暂回到「当前卡组」也不会把统计清掉。

    没显示的那个标签只是收起来了，计数一直在后台跑，切回来数字是对的。

  ● 调整窗口大小

    右下角的三条金色斜线是把手：按住往右下拖就能改长宽，宽度拉到 520px 以上
    牌库自动变双列，一次能看一倍的牌；双击把手 = 高度回到「内容多高就多高」。

  ● 关闭与重新打开

    点记牌器右上角的 ✕ 只是关掉这个窗口，控制台「影之诗」页的「打开」随时
    可以再打开，不需要重启助手；换卡组、调完设置也可以关掉重开。
    （1.1.1 修订：以前关掉之后「打开」会没反应，必须重启控制台才行。）

  ● 关游戏的时候（1.1.1 修订）

    开着记牌器直接关游戏，以前游戏会卡在退出流程里变成「未响应」，只能强杀。
    根子找到了：读取脚本把自己的一条线程**永久**登记进了游戏的垃圾回收器，
    而游戏退出时要做最后一次全量回收，回收器就一直在等这条线程点头 ——
    它永远不会点头，于是全场线程一起停住。
    现在这条线程只在「读一次类结构」的那一瞬间才登记，读完立刻退出，
    采样和读牌全程只读内存，不再碰游戏的运行时。

    另外：

      · 游戏刚起来、`GameAssembly.dll` 还没加载时不硬上，报一句就退开，
        十几秒后自己再来一次。
      · 启动不到 15 秒的游戏进程不注入；同一个游戏进程最多挂两次
        （多挂一次就多留一份钩子，容易互相拆台）。
      · 控制台不再「等不及就强杀」读取进程 —— 强杀会把钩子留在游戏里，
        游戏反而更关不掉。

    先关游戏再关控制台，或者反过来，都可以。

  ● 牌库排序（V1.0 新增）

    「牌库」那一行的右边有一个小按钮，上面写着当前的排序方式
    （`费用：低→高` / `费用：高→低`）。点它，下面弹出两个选项：

      · 费用从低到高（默认）
      · 费用从高到低

    每个选项前面有个圆点，没选的是空心圈，选中的是金色实心圈。
    点一下某一项，牌库立刻按这个顺序重排，浮窗同时消失 —— 整列会平滑地
    滑到新位置，不会闪、也不会从头重建。

      · 浮窗是压在最上面的一层，不占位置，牌库不会因为它往下挪；
      · 点浮窗以外的地方、滚轮、切「我方 / 对方」、折叠牌库、拉窗口大小，
        浮窗都会自己收起来；
      · 同一费用的牌保持原来的先后（先按职业，再按稀有度、名字），
        不会因为倒序就连同费用的牌也倒过来；
      · 只影响「牌库」这一段：手牌和对手已知不动（手牌本来就按费用排好、
        紧跟在手上，换个方向反而不好找）；
      · 排序只在这一次记牌器窗口里有效，关掉重开会回到「从低到高」。

  ● 类型颜色（V1.0 新增）

    记牌器每行右侧会标出这张牌的类型，三类各用一种暖色，扫一眼就能分出来：

      · 随从 —— 橙色
      · 法术 —— 金黄色
      · 护符 —— 玫红色

    「对方」标签里同样上色，只是暗一档，不会抢我方那边的注意力。
    以前那个「衍生物」分类已经取消：由卡牌效果生成的牌也按它自己的类型归进
    这三类（造出来的随从就是随从、造出来的护符就是护符）。纹章、加护、特性
    这类特殊对象不属于三类，只显示卡名，不带类型文字。

  ● 卡牌图片（1.1.1 新增）

    每一行左边有一张 37×48 的小卡面（跟费用圆章一样高），一眼能认出是哪张牌；
    鼠标停在**这行的卡图（含费用圆章那一小块）**上约 0.3 秒，会在记牌器旁边
    弹出这张卡的大图（挪开鼠标就收起）。停在卡名、类型、数量上不会弹，
    所以顺着名单往下扫不会一路弹图。
    如果大图刚好还没下完，它会自己等几秒，图一到就弹出来，不用重新悬停。

      · 图片来自官方：影之诗：凌越世界的卡表接口和官方图床（简体中文），
        只读公开数据，不需要登录，也不上传任何东西。
      · 第一次看到某张卡时，后台会下它的原图（约 0.5 MB），立刻缩成两张
        小图存到 svwb-probe\cache\cardart\，以后再看到就直接用本地文件。
        所以刚开始打的时候图会一张张陆续出现，属正常。
      · 断网、官方改地址、某张卡查不到图 —— 都只是「这一行没有图」，
        名字、费用、数量、胜负统计全都不受影响。
      · 想关掉：控制台「影之诗」页 →「记牌器里显示卡牌图片」取消勾选，
        关掉后连下载都停，行内也不留空位。
        勾选状态切换后要把记牌器关掉再打开，新的显示方式才生效。

    同一页还有两个按钮：

      · 「下载当前卡组」：把当前这套 40 张卡的图一次下完（约 20 MB 流量），
        开打前先点一下，进对局时就不会一张张往外蹦。
      · 「清理缓存」：删掉本地卡图（换版本、想省磁盘时用），下次会重新下。

    出了新卡包，跑这两个脚本（都在 svwb-probe 目录下）：

      python update_cardmeta.py         刷新卡名/费用/技能原文（约 1 分钟，先跑这个）
      python update_cardmeta.py --check 只想看看会改什么，不写盘
      python update_cardart.py          刷新卡图索引（几十秒）
      python update_cardart.py --fetch  顺便把所有卡图下全

    update_cardmeta.py 是**合并**：官方接口只给得到当前卡池里的 900 多张实战卡，
    本地还有大量异画变体和纹章/信仰/加护，刷新只覆盖接口给到的那部分，
    其余原样保留，不会因为刷一次反而丢卡。

  ● 历史胜率（V1.0 新增）

    控制台「影之诗」页，「记牌器」一行右边有两个按钮：`历史胜率` 和 `打开`。
    点「历史胜率」弹出的面板，记的是**每套卡组、每一天**各打了多少场、赢了多少：

      · 一张卡片 = 一套卡组。卡组名后面是张数，「当前使用」的角标是粉色，
        整张卡片的描边也是粉色，一眼能找到现在这套；
      · `共 60 场 · 胜率 52%` 是这套牌的总账；
      · `最近使用：11/9 · 共 4 天` 是最后一次打它是什么时候、一共记了几天；
      · 卡片最底下的下拉框在 `全部日期` 和具体某天之间切。选了某天，
        上面那行就变成 `11/8 · 20 场 · 胜率 60%`，下面那行变成
        `该日 12 胜 8 负`，翻明细不用另开窗口；
      · 最右边的红色「删除」只删这套牌的历史记录，**不动卡组本身**；
        面板左下角还有一个「清空全部记录」。
      · 「累计 N 场」那一行最右边有个 `按卡组统计 ▾`，点开能切成
        `按职业统计`：同一个职业下所有卡组的胜负相加（职业按卡表的 class
        反推，比如「中速梦」就是梦魇）。这个选择会记住，下次打开还是它；
        按职业看的时候卡片不显示「删除」（删一整个职业没有明确含义），
        右上角角标变成「含当前卡组」、中间显示「N 套卡组」。

    这些数字从哪来：就是记牌器顶栏的那个胜率。什么时候落账（记一笔 + 清零）：

      · 你在控制台「卡组」里**换成另一套牌**时 —— 自动把刚才那段记到旧卡组名下，
        然后把记牌器的胜/负清零，新卡组从 0 开始；
      · **北京时间 00:00** 时 —— 同样记一次再清零，所以「今天」和「昨天」是分开的；
      · 面板最上面那行「记牌器当前：xx 2 胜 0 负 · 尚未归档」就是还没落账的数字，
        再打几局、或者下次切卡组/过零点，就并进对应的那一天。

    几个细节：

      · 时间一律按北京时间算，电脑时区设成别的也不会把 00:30 的对局算到前一天；
      · 跨零点的那一夜能拆开记：23:50 的输记在昨天，00:20 的赢记到今天；
      · 一整天没打（0 胜 0 负）不会写一行「0 场」，也不会把记牌器清零；
      · 同一个卡组同一天切走又切回来，两次的场次会合到那一天，不会分成两行；
      · 卡组改名，历史记录跟着换名字（不会变成「新卡组 0 场 + 旧卡组一堆场」）；
      · 记牌器顶栏的「重置」还是纯清零，不写进历史 —— 想留档就切一下卡组；
      · 升级到 V1.0 后第一次打开不会动你正在看的那段胜率，只把账本开起来；
      · 这个「跨天检查」几乎不占资源：控制台每 15 秒看一眼日期和两个小文件的
        时间戳，没变化就直接跳过，不去解析、不常驻内存（实测一天累计约 0.1 秒
        CPU，连跑 3 万次内存也不涨），所以不会拖慢游戏或电脑。

  ● 现在能用到什么程度（重要）

    控制台模块和记牌器窗口已经就绪；**卡组读取需要进一局影之诗对战校准一次**
    （游戏内存里的对象位置会随版本变化）。没校准时窗口显示「未在对战中」，
    不会给出错的数据。

    如果内存里读不到完整卡组，可以手动导入（推荐）：
    把卡组写成 svwb-probe\gamedata\user_decks.json（可放多套）：
      {"decks":[{"name":"龙族","cards":[10403120, ... 共 40 个卡 id]}]}
    或单套 user_deck.json：{"cards":[ ... 共 40 个卡 id ]}
    开局会按手牌自动选匹配的一套；对不上时不显示「牌库中」，不会给错数。

    更省事：直接用卡组码导入——
    把游戏里生成的卡组码（`#巫师(2)#` 开头、里面有 `1.3.xxx` 那一行）存成文本，
    运行 `svwb-probe\python.exe deckcode.py --file 卡组码.txt`，会输出 40 张卡的 id；
    也可以把码直接写在 --code 后面。解码不需要联网。

  ● 卡组管理（控制台「影之诗」页）

    · 「导入卡组码」：粘贴游戏里生成的卡组码 → 解析 → 保存（同名覆盖）。
    · 「查看已导入」：列出所有卡组，可「设为当前」和「重命名」。
      「设为当前」= 记牌器优先用这套；如果手牌明显对不上，会自动回退到匹配的那套，
      不会显示错卡组。

  ● 和影之幻境互不影响

    两个模块在同一个控制台里切换；记牌器单独一个窗口，可以拖动、关闭。

【十八、出问题怎么反馈（重要）】

发现胜率不对、面板不显示、闪退、掉血对不上……都按这个来，能最快定位：

● 第一步：双击 收集诊断信息.bat

  它只读取、不改任何设置、不碰游戏，会在包里生成：

    诊断包\HJ诊断-<时间>.zip

  里面自动装好：
    - 日志\       判定器 / 面板 / 控制台的日志（含 光环解析失败.log、环境检查.log）
    - 数据\       overlay.json、战绩、各种设置、窗口位置
    - 对照证据\   每场战斗自动存的「画面截图 + 当时的内存读数」← **找读数/规则错误最有用**
    - 游戏日志\   游戏自己的 Unity 日志尾部（有才带）
    - 环境\       Python / Node 版本、屏幕分辨率与缩放、相关进程

● 第二步：补几句话（比日志还重要）

  1. 大概什么时候、哪一局
  2. 看到的现象（胜率明显不对 / 面板不显示 / 掉血对不上 / 闪退……）
  3. 你期望它是什么样
  4. 能不能稳定复现（每次 / 偶尔）
  5. 当时游戏在干什么（开战瞬间 / 运营阶段 / 刚开一局 / 结算画面）

● 第三步：把 zip 直接发过来

  不需要别的文件，也不需要你整理日志。
  唯一提醒：zip 里可能有游戏画面截图，转发前自己看一眼。

● 需要游戏的运行日志吗？

  通常**不需要**。"收集诊断信息"会自动带上游戏 Unity 日志的尾部；
  但绝大多数问题（胜率/掉血/面板）跟我们自己读的数、算的规则有关，
  真正有用的是「对照证据」里那张截图 + 当时的内存读数。
