## 测试过程中发现并修掉的问题

1. **Tk 窗口未 map 时设置 `-topmost`，窗口会落在其它 topmost 面板下面** → 启动后 250 ms 再 `SetWindowPos(HWND_TOPMOST, NOACTIVATE)` 断言一次；
2. **JSON 损坏时 mtime/key 不变会跳过重试** → 解析失败后重置 key，下个 400 ms 周期继续重试；
3. **窗口被系统移动时顶层不一定触发内容布局的 `<Configure>`** → `--rect-out` 增加每秒兜底刷新，实测移动后 1 秒内更新；
4. **Win11 圆角会透出桌面，截图四角出现白色小三角** → 用 DWM `DWMWA_WINDOW_CORNER_PREFERENCE=DONOTROUND` 关掉圆角，并设深色标题栏；
5. **长异常文本会盖住页脚** → 屏幕上只显示用户能理解的提示，技术细节写 `--log`；
6. **全局 Esc 关闭容易在直播时误触** → 去掉全局 Esc；`--borderless` 模式提供右上角 `×`；
7. **Tk geometry 把负坐标当成“距右边/底边的距离”** → 初始定位、拖动、无边框缩放全部改用 Win32 `SetWindowPos` 绝对定位；`--x 40 --y 40` 从实测 y=1416 修正为 y=40。
